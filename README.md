# 🎀 صفحة عيد الميلاد — دليل الرفع على Render

## الملفات

```
index.html              ← الصفحة (إلزامي)
render.yaml             ← إعداد Render والصلاحيات (إلزامي)
manifest.webmanifest    ← لتثبيتها كتطبيق
icon-180.png
icon-512.png
edit.m4a                ← الأغنية ✓ (مرفقة)
kai.jpg                 ← اختياري (صورة البولارويد)
shout.mp3               ← اختياري (صوتك وأنت تصرخ)
```

> ملف الأغنية **مرفق وجاهز** — ارفعه مع بقية الملفات كما هو.
> الصفحة تجرّب هذه الأسماء بالترتيب تلقائيًا:
> `edit.m4a` → `reflection edit.m4a` → `reflection.m4a` → `song.mp3` → `song.m4a`
>
> إن كان اسم الملف يحتوي كلمة **edit** فستعتبره مقتطعًا مسبقًا وتبدأه من الثانية صفر.
> أما إن رفعت الأغنية كاملة، اضبط ثانية البداية من زر **✎** داخل الصفحة.

---

## ① GitHub

1. **github.com** → زر **+** → **New repository**
2. الاسم: `for-kai` — اختر **Private** — **Create repository**
3. **uploading an existing file** → اسحب كل الملفات (بما فيها ملف الأغنية) → **Commit changes**

> من الآيباد: افتح github.com في Safari، ثم زر `ﮑﮑA` → **Request Desktop Website** ليظهر زر الرفع.

---

## ② Render

1. **render.com** → **Get Started** → **GitHub**
2. **New +** → **Static Site**
3. اختر مستودع `for-kai` → **Connect**
4. الإعدادات (يقرأها Render من `render.yaml` تلقائيًا):
   - **Build Command:** اتركه فارغًا
   - **Publish Directory:** `.`
5. **Create Static Site**

بعد دقيقة يظهر الرابط:

```
https://for-kai.onrender.com
```

**كل شيء يعمل من هنا:** الميكروفون · مستشعر الإمالة · تشغيل الأغنية.

### لتغيير الرابط
Settings → **Name** → غيّره إلى ما تشاء.

---

## ③ تحويلها إلى تطبيق على الآيباد

1. افتح الرابط في **Safari** (وليس Chrome)
2. زر المشاركة ⬆️ → **إضافة إلى الشاشة الرئيسية**
3. تظهر أيقونة الكيكة 🎂 — وتفتح بملء الشاشة بلا شريط متصفح

---

## ④ العدّاد التنازلي

الصفحة **مقفلة** حتى:

```
٢٦/٠٨/٢٠٢٦ · ١١:٥٩ مساءً بتوقيت السعودية
```

قبل ذلك تُظهر العدّاد فقط، ولا يُحمَّل أي شيء من محتوى عيد الميلاد.
في اللحظة المحددة **تفتح وحدها** بلا تحديث للصفحة.

**للاختبار قبل الموعد** أضف في آخر الرابط:

```
https://for-kai.onrender.com/?open=1
```

⚠️ **احذف `?open=1` عند إرسال الرابط لها.**

### لتغيير الموعد
في `index.html` ابحث عن:

```js
targetUTC : Date.UTC(2026, 7, 26, 20, 59, 0)
```

الشهر يبدأ من صفر (`7` = أغسطس)، والوقت بـ **UTC** — أي وقت السعودية ناقص ٣ ساعات.

## ⑤ التعديل

كل النصوص في أعلى `index.html` داخل `const DATA = { ... }`:
الاسم · الرسالة · التوقيع · الأسئلة · وعود العجلة · رسائل الفوز · عدد الشموع.

أو من داخل الصفحة بزر **✎** (بما فيه رفع الصورة والأغنية للتجربة).
